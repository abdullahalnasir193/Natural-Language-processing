# Lab 1: Introduction to Natural Language Processing

This lab provides a basic introduction to **Natural Language Processing (NLP)** and its common applications.

## Objectives

* Understand the basic concept of NLP.
* Learn why processing human language is challenging.
* Explore common text file formats and NLP applications.
* Become familiar with the NLTK library.
* Download, open, and explore a text dataset.

## Dataset

This lab uses the **IMDB Dataset of 50K Movie Reviews**.

The dataset contains two columns:

* `review`: The movie review text.
* `sentiment`: The sentiment label (`positive` or `negative`).

The dataset includes 50,000 reviews divided equally between positive and negative sentiments.

## Tasks

1. Select and download a text dataset.
2. Open the dataset using Pandas.
3. Display the first rows of the dataset.
4. Inspect the dataset structure and data types.
5. View the distribution of sentiment labels.

## Libraries Used

* Pandas
* NLTK
* KaggleHub
