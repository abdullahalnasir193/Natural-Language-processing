# Natural-Language-processing-Labs
This repository contains my laboratory work for the **Natural Language Processing (NLP)** course.

Each folder includes the Jupyter Notebook, code, and any datasets required for the corresponding lab.

## Repository Structure

```text
NLP-Labs/
├── Lab-01/
├── Lab-02/
├── Lab-03/
└── README.md
```

## Tools

* Python
* Jupyter Notebook
* Pandas
* NLTK

Additional libraries may be used depending on the requirements of each lab.

## Running the Labs

1. Download or clone the repository.
2. Open the required lab folder.
3. Launch the Jupyter Notebook.
4. Run the notebook cells in order.
